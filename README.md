# Vortex

Independent experimental Windows compatibility research, using original source and synthetic test programs only.

## Status

Early research scaffold. No commercial title is supported; no game execution, console API implementation or GPU translation is currently available. This repository is not a continuation or mirror of any removed repository, and does not include proprietary game files, leaked material, encryption keys, or circumvention tools.

The initial milestone is a read-only executable-format inspector and reproducible tests using generated fixtures. Future work is limited to independently authored, authorized test programs and documented interfaces.

Not affiliated with Rockstar Games, Take-Two or Microsoft.
